# Memory Glass 1.3 — 菜单栏常驻与分发

## 用户目标

登录 macOS 后自动启动，只显示菜单栏内存百分比。点击百分比展开原生毛玻璃浮层，快速查看总内存状态和内存占用最多的 10 个应用；需要时进入完整面板。交付本地 Mac 安装包，并将完整源码上传至用户指定的私有 GitHub 仓库。

## 设计

采用 AppKit 的 NSStatusItem 与 transient NSPopover，浮层内容由 SwiftUI 展示，使用系统材质、系统字体、应用图标和对齐的数值。展示总体使用率、使用容量、压力状态和按已知内存排序的前 10 个应用。应用占比均以物理内存总量为分母，辅助进程沿用现有分组规则。

同一个 MemoryStore 提供状态栏、浮层和完整面板的数据。应用由 NSApplicationDelegate 持有，冷启动不创建主窗口；完整面板由用户按需打开，保持单窗口并保留强制退出的确认和保护措施。关闭窗口不结束采样，退出应用才停止监测。

使用 ServiceManagement 的 SMAppService.mainApp 管理登录项。在标准应用目录首次运行时尝试注册，显示系统返回的实际状态；等待系统批准和失败不显示为已启用。用户关闭后不重复自动注册。浮层提供登录启动开关和异常说明。

安装包使用系统 pkgbuild，把应用安装到 /Applications，不使用以 root 运行的安装后脚本。另提供 DMG 拖拽安装方式。当前构建面向 Apple Silicon、macOS 14 及以上；无 Developer ID 证书时准确标明未公证的本地分发版本。

## 验证

编译、采集器与安全退出回归测试；菜单栏状态、Top 10 选择、登录项状态和首次启用策略测试；检查冷启动、关闭窗口继续采样及浮层/完整面板行为；校验安装包有效负载、应用签名结构、ZIP 完整性；上传前排除本机采样数据、构建产物和敏感信息，远程核对仓库可见性与提交。
